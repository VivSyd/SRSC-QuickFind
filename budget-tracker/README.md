# Budget Tracker (Web)

This is a standalone personal budget tracker app built from your spec.

## Run

1. Open `budget-tracker/index.html` in your browser.
2. Use tabs for Home, Payday, Accounts, Bills, Log Spend, Today, Savers, Weekly, Alerts.

## Included Features

- Weekly income and expense tracking (Monday week start)
- Payday auto-split with shortfall priorities
- Accounts list with editable balances
- Bills with due date sorting, funding status, mark paid, add/edit
- Spend logging with category tracking and limit warnings
- Daily summary with status indicator
- Savers allocation from Up Savers
- Weekly summary with week selector and CSV export
- Alerts with fix-now navigation
- Status indicators: `??`, `??`, `??`
- AUD currency formatting
- Local persistence via `localStorage`

## Notes

- Payday default day is Wednesday.
- Fixed expenses are set to `$718`.
- Initial bill due dates are seeded for 2026.
